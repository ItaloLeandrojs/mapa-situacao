# Mapa de situação

Site estático que lê o arquivo KML ou KMZ do Google Earth e devolve o mapa de situação em DXF. O KML nunca sai do navegador.

## Como rodar

- `npm install`: instala as dependências
- `npm run dev`: abre o site em modo de desenvolvimento
- `npm test`: roda os testes
- `npm run build`: confere os tipos e gera o site em `dist`
